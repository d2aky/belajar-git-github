# belajar-git-github
ini adalah rangkuman poin - poin yang saya dapat dalam pelatihan **git/github** di kelompok 2 bersama bang [Ikram Fuadi Rambe](https://github.com/fuadi0010)

## tentang rangkuman
rangkuman ini saya buat berdasarkan pada apa yang saya dapat dalam pelatihan. Ketika pelatihan dimulai, saya langsung membuat catatan di notepad maupun dalam file di vscode. semua catatan itu saya rangkum kedalam file txt, sebagai bentuk catatan utama saya dalam pelatihan ini. tujuan dari pembuatan file ini adalah sebagai tempat saya melihat materi materi yang sudah disampaikan di pelatihan - pelatihan yang sudah lewat, dan menjadi pengumpulan catatan - catatan kecil saya pada pelatihan yang akan datang. 

### **NOTE :**
ini bukan file yang dibuat karena tugas dari instruktur pelatihan, tapi karena kebetulan tugasnya sama dengan yang sudah saya buat ini, sehingga saya memutuskan untuk mengirimkan link ini sebagai tugas.
